# Asset and code provenance

- Controller reference: Godot official Platformer 3D demo, MIT. Source snapshot under production_godot/vendor/godot-demo-projects/3d/platformer. Locomotion is adapted for a small doll; new narrative and interfaces are original.
- Existing WAKUKU character: user reference / Tripo production, edited and skinned in the project's Blender pipeline. 25 bone poses baked through the existing Unity humanoid avatar.
- Interaction actions: user-supplied Interactions Animations v1.1, from 奇梦岛. Pickup, look-distance, goodbye, talk, laugh. Original package terms apply; no raw asset redistribution as a standalone pack.
- Ecological flora: user-supplied 风格化生态自然资产包 / Flora_Mat&GN&Models.blend and Flora_1 atlas. Original terms apply.
- Architecture, terrain, trees, butterflies and birds: existing WAKUKU authoring project and its asset manifest, including user supplied POLYGON Meadow Forest and CC0 Kenney kits.
- Chinese jump vocalizations and original narrative voice: Merouter seed-tts-2.0, 2026-10-28. Existing project music and foley retained.
- The Little Prince is a thematic reference for care, connection and returning; all dialogue in this project is newly written.
